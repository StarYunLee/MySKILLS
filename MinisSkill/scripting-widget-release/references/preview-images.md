# 展示图

## 素材

- 只用用户提供的**原始真机截图**。
- 禁止从已合成展示图二次裁切或放大。
- 需要构图参考时：量 GitHub 旧图的卡片比例、等高、组距、标签位置，再把新截图嵌进去。
- 用户给整图预览并说不要抠卡：按统一裁框拼，保留截图自身背景，只去掉状态栏 / 页码 / Dock 等无关 UI。
- 未收到新截图时，不要用旧展示图宣称“可上传”。

## 画布

- 仓库历史常用 `1800×1130`，**不是硬约束**。
- 若按旧画布会明显发糊或大面积留白：改用更贴内容的尺寸（例如 Grok 1.5.0 的紧凑宽图），并在当次说明为什么偏离。
- 输出 RGB PNG。卡片阴影可留，预览器 UI（状态栏、页码点、Dock、Scripting 编辑框）要去掉，除非用户要求保留 Scripting 标签。

## 清晰度

- Small / Medium 尽量接近原始像素放置，避免先缩小再放大。
- 多卡并排时保持等高、间距可读。
- 中文标签用系统中文字体（PingFang SC）；英文标题可用 Inter。不要用会把中文拉变形的西文字体写中文。
- 用户嫌糊或留白：先改构图，不要先加锐化。

## 同步

展示图定稿后：

1. 写入项目 `assets/*-preview.png`
2. 同步到候选目录
3. 重打 `.scripting`
4. 确认包内预览与源文件哈希一致

## 过程中

像素/文案还没定：先改源码和预览，最后一起出图打包。用户明确说「暂时不要重复打包」时遵守。
