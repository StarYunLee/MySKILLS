# ACTION_PARAM_INDEX

## 作用

高频动作的参数速查表。生成 XML 时先查此表确认必填键、序列化方式和常见错误，不用翻 BEST_PRACTICES 全文。

## 速查约定

- **必填** = 缺少会导致验证失败或导入异常
- **推荐** = 不写也能导入，但缺少会降低可用性
- **序列化** = 该参数应使用的 `WFSerializationType`
- **TokenString** = `WFTextTokenString`（带 `￼` + `attachmentsByRange`）
- **Attachment** = `WFTextTokenAttachment`（纯变量引用，无包裹文本）
- **Variable wrapper** = `{ Type: "Variable", Variable: { Value: ..., WFSerializationType: "WFTextTokenAttachment" } }`

## 4. Replace Text

| 标识符 | `is.workflow.actions.text.replace` |
|--------|-------------------------------------|
| OutputName | `Updated Text` |

| 参数 | 必填 | 类型 | 说明 |
|------|------|------|------|
| `UUID` | ✅ | string | |
| `WFInput` | ✅ | **TokenString** | ⚠️ 引用 ActionOutput 时**必须用 TokenString**，不能用裸 Attachment |
| `WFReplaceTextFind` | ✅ | string | 查找文本/正则 |

## 显示参数 vs 数据流参数速查

| 参数类别 | 序列化方式 | 典型参数 |
|---------|-----------|---------|
| **显示参数**（用户可见文本） | **必须 TokenString** | `WFAlertActionMessage`, `WFAlertActionTitle`, `WFNotificationActionBody`, `WFNotificationActionTitle`, `Text`(ShowResult) |
| **数据流参数** | 可用 Attachment | `WFInput`, `WFDate`, `WFVariable`, `WFDictionary`, `WFNote`, `WFFile` |

**用 Attachment 写显示参数 → 运行时字段显示为空。** 这是最常犯的错误之一。
